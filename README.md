# AI Customer Support Assistant

A Python-based customer support assistant powered by a locally running Llama 3.2 model through Ollama.

## Features

- Generates customer-support replies
- Uses a local LLM
- Supports different customer requests
- Produces professional responses
- Does not require a paid AI API
- Runs locally on Windows

## Technologies

- Python
- Ollama
- Llama 3.2

## How It Works

Customer Message
       ↓
Python Application
       ↓
Ollama
       ↓
Llama 3.2
       ↓
AI Generated Reply
